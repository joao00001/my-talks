# my-talks

A public collection of my talks and presentations (slides), mainly from PostgreSQL conferences (pgconf) and similar events.

## Structure

```
talks/
└── <year>-<event>/
    ├── README.md       # Talk context and metadata
    ├── slides.pdf      # Final slide deck
    └── assets/         # Optional images/files used by the talk
```

Each talk lives in its own directory under `talks/`. Open the directory's `README.md` for a description and links to slides.
